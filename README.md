
# NCM 格式转换器 (GUI)

本项目是一个基于 PyQt5 开发的网易云音乐加密格式（`.ncm`）转换工具的图形用户界面（GUI）。它旨在为用户提供一个直观、便捷的操作界面，通过后台调用底层解密引擎，实现 NCM 格式向通用音频格式（MP3 / FLAC）的批量转换与自动整理。

## 本程序已打包测试，请在最近的releases里下载进行使用。

若您需要自行修改打包，请按readme里的详解操作

---

## 功能特性

1. **直观的拖拽交互**
   * 支持将单个 `.ncm` 文件、多个文件或整个文件夹直接拖拽至软件界面。
   * 软件会自动筛选出有效的 `.ncm` 文件，避免导入无关格式。

2. **状态可视化列表**
   * 采用自定义列表控件（`SongItemWidget`），实时显示导入歌曲的转换状态（待转换、已转换、转换失败）。
   * 转换失败的歌曲支持悬停查看失败原因，交互体验清晰。

3. **自定义导出路径**
   * 支持自主选择转换后的音频存放目录。
   * 转换完成后，软件会自动执行文件完整性校验（确保非空文件），并自动移动至指定目录，保持原文件夹整洁。

4. **静默后台处理**
   * 转换引擎在后台静默运行，不会弹出黑色的命令行窗口，保证界面美观度。

## 运行环境与依赖

* **操作系统**：Windows 10 / 11 
* **开发语言**：Python 3.8+
* **主要依赖**：
  * `PyQt5` (用于构建图形界面)
  * `shutil`, `subprocess` (系统标准库，用于文件操作及调用外部引擎)

### 安装依赖
在使用源码运行前，请先安装 PyQt5：
```bash
pip install PyQt5
```

---

## 项目结构与使用说明

### 1. 文件准备
在运行本程序前，请确保您的项目根目录下包含以下两个核心文件：
* `main.py`（本程序的 Python 源代码）
* `Ncm转mp3拖一拖.exe`（底层的转换引擎，程序运行时需要调用它）

### 2. 启动程序
在终端执行以下命令运行程序：
```bash
python main.py
```

### 3. 操作步骤
1. **导入文件**：将需要转换的 `.ncm` 文件拖入软件中心的蓝色虚线区域。
2. **选择路径**：点击“选择文件夹”按钮，指定转换后音频的保存位置。
3. **开始转换**：点击“开始转换并导出”按钮，程序将自动处理并输出结果。

## 打包为独立运行程序



本程序在设计时已考虑了 PyInstaller 打包兼容性（通过 `get_resource_path` 函数动态获取临时路径）。

如果您需要将其打包为单文件 `.exe`，请确保将转换引擎作为资源文件一同打包：
```bash
pyinstaller --noconsole --add-data "Ncm转mp3拖一拖.exe;." main.py
```
